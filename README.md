# Before the Close · 交割之前

原创 VC/PE 项目尽调题材的单人正交探索 RPG。复用引擎来源：Yinxinghuan / AlterU，Stateful Story Template（https://github.com/yinxinghuan/stateful-story-template ，冻结 24ed1f5，强化至 cafd0fe）及 build-spatial-story-game 技能；React 与 Lucide 许可全文随 THIRD_PARTY_NOTICES.txt 分发。全部正式游戏美术和声音通过 AlterU Media Service 生成。

四个地点、五位人物、十份资料、三项证据判断、两种谈判条件与三类结局。没有实时倒计时；可以随时中断，同浏览器继续。

## 运行
Node 24：npm ci；npm run dev；npm run build；npm test。

## 游玩
[正式主站](https://game.aiwaves.tech/233b6970-d7f6-4d54-bc20-4213eefc6ba5/) · [Pages 镜像](https://yinxinghuan.github.io/before-the-close/)

使用摇杆/方向键或点击地面移动。点击目标先走近，再按行动键。资料夹内选择两份来源核对判断。签署意见后可复查，另开旅程比较决定。

## 交付边界
公开试玩版使用服务器旅程和浏览器匿名身份，无需测试账号，不承诺跨设备恢复；原版存档不导入。作者主线配合有限额 AI 对话与补充调查，动态房间仍需独立人工复核后由玩家采纳。AI 不提供真实金融数据或投资建议。清除浏览器数据会失去该身份的旅程入口。Pages 仅为静态源码镜像，不连接正式数据库。真人理解和节奏仍待试玩。当前架构见 doc/public-release-20260930.md；美术与历史实现见 doc/technical.md。
