# 门素材分型复验

本轮固定两种用途，均平台纯文本、零参考；平台模型别名gpt-image-2.5-sunburst。
- front-framed-v2：N/S正面完整门，包含固定门框与门叶；关闭状态。
- side-leaf-v2：E/W侧门独立门叶，不带固定门框；装配到打开的侧门，图像本身保持轴向正投，不斜转。
- front-open-leaf：用户已拒绝，生成前混淆用途并加入斜转窄侧视指令，不能靠缩放修正。

验收分别记录原图与合成。未通过原图不得装配；新生成关闭正面门不得直接覆盖可通行门洞，必须有对应开门状态再接运行。

v2原图审查：正面有框主体高宽比1.693，仍偏高；侧门主体1.428，但把手底座近圆，不能仅凭外形比值通过。两张均拒绝运行准入。v3改为先描述短矩形与55度俯视下五金几何，后描述用途；仍然零参考，不允许事后压缩高度。

v3进入renderer候选：front-framed-v3带框，side-leaf-v3无固定框；原图轴向、薄顶与五金较v2改善。前门完整素材按68世界宽等比；frame-open从同张图移除活动门扇像素得到，原图全尺寸不变，无压扁/重绘。角色距门接近点100以内显示空框，离开显示关闭整门；不声称平滑铰链动画。侧门按48宽等比，西门允许整图镜像（无文字），右门原图右铰链贴墙。此前斜门叶已从runtime coverage移除，源文件保留为拒绝证据。
