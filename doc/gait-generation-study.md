# 主角后向步态生成实验（2026-09-21）

## 目的

用户在实际图集中发现后向 `motion A` 与站立帧过于接近。运行时确实在切换纹理，但视觉上仍像滑动。本实验固定 Ava Morgan 的身份、服装、比例、后向正投镜头与输出尺寸，只比较生成姿态的方法。

## 方法与结果

所有 10 张候选均由 AlterU 平台媒体服务 `edit` 模式生成，使用同一永久游戏 session。任务两路并发，总墙钟约 65.4 秒；单任务从 8.2 到 20.2 秒。原图、request ID、task ID 与 SHA 均保存在 `materials/gait-study-up-left-*.{png,json}`，编号对照图为 `_qa/gait-study-contact-sheet.png`。

## 可复用结论

1. 先生成并签收一张明确的接触相，再以它为编辑参考生成相反支撑相，比从站立帧生两端稳定。
2. 提示词优先描述屏幕坐标中的前脚、后脚和两只鞋的分离，并锁定头、肩、外套和相机。
3. “缩略图也要明显”或大量负面禁止会诱发横跨、跑步或夸张姿态，只能作为拒绝条件，不能作为主要姿态指令。
4. 自动检测到 `A / stand / B` 三张纹理被切换，只能证明运行时正确；必须把三帧按实际显示高度装配后检查腿部轮廓。

正式图集采用 01，原不合格后向左支撑帧保留在材料目录作为失败证据。
