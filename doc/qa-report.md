# 验收记录 · 2026-09-20
## 范围
macOS headless Chrome，正式 Vite dist，390×844 / 320×568。不是 iPhone 真机，也不是新玩家理解测试。设计目标20–30分钟尚待真人计时。
## 功能
- _qa/playthrough.mjs：两尺寸从新档经四场景、五人首次介绍、十份资料、三项证据、客户确认、创始人协商、返回投委会、签署、刷新恢复。390测试分期；320测试重定价。实体 DOM 目标使用正常键盘激活触发寻路，不传送。首次介绍结束后的前两个可用话题检查实际边界。
- _qa/recovery-audio.mjs：巡游位移、实际距离脚步、静音、独立旅程、原条件结局、坏档保留/备份恢复。暂停结局单独使用明确标注的前置事实fixture，不能说成第三次完整徒步通关。
- _qa/state.test.ts：五项领域/可达性测试；包括提交后证据快照不被新增调查改写。
- _qa/audio-live.mjs：真实音频元素readyState、paused与currentTime推进，全局静音/恢复及读档后移动解锁。记录不等于人工试听。
## 视觉
doc/evidence 保存四场景、两尺寸对话、地图、资料、头像、结局、英文设置及外部访客图。场景取景使用明确QA定位，通关截图来自实际行走。无访客栏为主构图，未修改生产guest-shell。
初轮发现家具过大、门洞补地擦掉人物、首次介绍挤掉选项；已调整尺度与绘制顺序、压缩可滚动正文，并在同类状态复拍。主角保留统一方向图集，拒绝了后续比例与支持腿不一致的候选；整帧镜像右向，没有局部肢体拼接。
## 声音边界
平台音乐45秒，音乐增益-4dB并加淡入淡出，运行音量0.18；脚步0.55、纸张/门0.4。音乐、事件、UI声音已提供，独立环境底噪与人声为本章创意省略。已验证格式、峰值及浏览器播放；本执行环境未完成真人全曲听感审核，循环接缝与真实手机混音留为试听项，不能宣称听感已经验收。
## 技能
隔离临时目录脚本包回归通过；主角同任务多格正例、同格复用/伪造格hash/局部反射负例均按预期。包完整和机械通过不代表陌生agent能一次得到合格美术。详见skill-evaluation.md。

## 第二轮游戏收口检查
领域测试扩为8项，增加切旅程/新旅程实时落点、回访时钟不倒退、签署后拒绝重新协商。_qa/completion.mjs以真实指针检查两尺寸摇杆中心死区、跟手偏移、松手归中与旅程回切落点；完整通关脚本继续覆盖原有章节。平台列表操作本轮明确排除。
