# r8.4 地图与题材化背包

沿用现有美术。地图改为暖纸底路线图，当前位置与选中目的地分别表达，真实门连接生成路线，逐段从door-layout读取门方向，支持定位/全图/缩放按钮/拖动/双指缩放。不改变游戏位置。

资料夹含目标、资料、判断、人物四模块。目标页显示当前任务和已知状态统计；人物含已发生的往来、角色信息和肖像放大。未认识人物不显示；所有计数只算已收集/认识/核实内容。切模块滚动归顶。原资料全文、资料对照和判断仍保留。

技能交接包采用按题材模块组合，物品可记录数量/用途/来源/借还状态与权威动作；不要求统一标签或布局。投资题材没有装备或消耗物品玩法，不伪造数据；这些动作需另在物品消费者验证。新增规范、配置例子、通用有向路线函数都在r8.4 ZIP内。

19项单测通过，包含有向路径/环/断开连接；包内48项原有独立解压门禁通过，不等于新物品动作已跑通。两尺寸地图多段路线、缩放定位、资料空态、首次见面后往来及头像放大通过。秘密/API/UI图标审计通过。共享技能源目录同步审批超时，当前r8.4 ZIP是新增规范的交付真源；本地解压源在doc/skill-handoff/r8.4-source。

完整正式构建流程：390×844、320×568均通过资料收集、NPC交谈、判断、不同条件谈判、结局及刷新恢复，零pageerror。
